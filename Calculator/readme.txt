Calculator provides for the user 6 operations.

1) Addicting
2) Subtraction
3) Division
4) Multiplication
5) Percentage calculation
6) Square root calculation

Addicting and multiplication can take multiple variables, others 1 or 2.

To start work with calculator choose the operation by entering numbers from 1 to 6.
