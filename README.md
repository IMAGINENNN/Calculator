# Calculator

# Project description
﻿Calculator provides for the user 6 operations.

1) Addicting
2) Subtraction
3) Division
4) Multiplication
5) Percentage calculation
6) Square root calculation

Addicting and multiplication can take multiple variables, others (Percentage calculation, Square root calculation ) 1 or (Subtraction, Division) 2.

Args:
      values [](double): array
      value (double):

Returns:
      result (double): Calculated number
      
# User guide
To start work with calculator choose an operation by entering numbers from 1 to 6.

Then follow instructions and enjoy the process)
